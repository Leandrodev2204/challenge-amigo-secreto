# Amigo Secreto

Aplicação web que sorteia participantes de um amigo secreto, desenvolvida como desafio prático de lógica de programação com JavaScript.

## 🎯 Objetivo

Praticar manipulação de listas, eventos e DOM em JavaScript através de um desafio guiado, implementando a lógica de cadastro de nomes e sorteio de um amigo secreto.

## 🚀 Funcionalidades

- Cadastro de participantes
- Sorteio automático do amigo secreto
- Validações de entrada (ex: nomes duplicados ou campo vazio)

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
